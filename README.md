# Automation Playwright Case

Кейс автоматизации на Node.js и Playwright для рабочего процесса перевода сценариев через веб-интерфейсы Gemini, ChatGPT и Google Docs.

## Что делает проект

- Берет исходный текст из Google Docs или локального файла.
- Разбирает сценарий на пронумерованные части и проверяет количество символов.
- Автоматически отправляет части в Gemini или ChatGPT через управляемый Chrome.
- Ждет готовый ответ, очищает лишний текст интерфейса и собирает итоговый документ.
- Сохраняет результаты локально и при необходимости создает новый Google Doc с переводом.
- Дает удобное меню запуска через `start.command` и отдельные команды для каждого сценария.

## Основные сценарии

- `npm run gemini` - перевод на выбранные языки через Gemini.
- `npm run english` - английский перевод через ChatGPT.
- `npm run count` - подсчет символов в частях исходного Google Docs.
- `npm run check` - быстрая проверка синтаксиса JS-файлов.

На macOS можно запустить `start.command`: он открывает меню, проверяет Node.js/npm, поднимает Chrome с remote debugging и запускает нужный сценарий.

## Принципы реализации

- **Browser automation вместо ручной рутины.** Playwright подключается к Chrome через CDP и управляет реальным браузером с авторизованными аккаунтами.
- **Сохранение контекста.** Для Gemini скрипт запоминает URL текущего чата и при повторной отправке не теряет разговор.
- **Надежность на длинных задачах.** Есть паузы между запросами, повторные попытки, ожидание стабилизации ответа и корректная обработка остановки через `Ctrl+C`.
- **Работа с документами.** Google Docs читается через экспорт в txt, а при необходимости открывается в браузере для авторизации и записи результата.
- **Контроль качества текста.** Перед переводом скрипты нормализуют пробелы, считают символы и сверяют заявленный размер частей с фактическим.
- **Чистая структура.** В корне оставлены основные JS-скрипты и точка входа, а команды, ассеты и runtime-данные разнесены по папкам.

## Структура

```text
translator-gemini-web.js       # основной сценарий перевода через Gemini
translator-chatgpt-english.js  # английский перевод через ChatGPT
count-source-chars.js          # подсчет символов в исходном документе
start.command                  # меню запуска для macOS
commands/                      # shell-команды для отдельных режимов
assets/notification/           # звук уведомления после завершения
app-data/                      # локальные профили и результаты, не коммитятся
```

## Запуск

```bash
npm install
npm run check
npm run gemini
```

Для работы нужны Node.js, npm, Google Chrome и авторизация в нужных веб-сервисах. Локальные данные браузера, результаты переводов и `node_modules` исключены из репозитория.
